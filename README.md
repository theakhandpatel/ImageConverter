## Description

PurePixels is a local image converter that allows you to convert images directly in your browser without uploading them to the cloud. This ensures your privacy and security while providing a seamless and efficient image conversion experience.

## Features

- **Local Processing**: Convert images directly in your browser—no uploads, no cloud.
- **Multiple Formats**: Easily switch between PNG, JPEG, WebP, GIF, BMP, ICO, TIFF, and more.
- **Batch Processing**: Handle multiple images at once for quick conversions.
- **User-Friendly Interface**: Simple and intuitive design for easy use.

## Installation

To run PurePixels locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/theakhandpatel/ImageConverter.git
   ```
2. Navigate to the project directory:
   ```sh
   cd ImageConverter
   ```
3. Install the dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm run dev
   ```

## Usage

1. Open your browser and navigate to `http://localhost:3000`.
2. Drag and drop images into the dropzone or click to upload.
3. Select the desired output format for each image.
4. Click "Convert" to process individual images or "Convert All & Download" to process all images at once.
5. Download the converted images.
